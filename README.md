A userscript that changes claude.ai so that Enter inserts a line break and Ctrl+Enter (Command+Enter on Macintosh) sends the message.

## Usage

### Installation

1. Install any userscript manager
2. Click `claude-ctrl-enter-send.user.js` in the `Assets` section of the [latest release](https://github.com/KOTO28/claude-ctrl-enter-send/releases/latest)
3. Follow the instructions from your userscript manager to install

### How to Use

1. Go to [Claude on the web](https://claude.ai/)
2. Lets you use Enter to insert a line break and Ctrl+Enter (Command+Enter on Macintosh) to send messages

## Notes

- Tested and confirmed working with Floorp + Violentmonkey
- The script may stop working if Claude changes its page structure
