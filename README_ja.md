claude.aiでEnterを改行に、Ctrl+Enter(MacintoshではCommand+Enter)を送信に変更するユーザースクリプト

## 使い方

### インストール

1. 任意のユーザースクリプトマネージャーをインストール
2. [最新のリリース](https://github.com/KOTO28/claude-ctrl-enter-send/releases/latest)の `Assets` にある `claude-ctrl-enter-send.user.js` をクリック
3. ユーザースクリプトマネージャーの指示に従ってインストール

### 使用方法

1. [Web版Claude](https://claude.ai/) にアクセス
2. Enterキーで改行、Ctrl+Enter(MacintoshではCommand+Enter)で送信が可能になります。

## 注意事項

- Floorp + Violentmonkey での動作を確認しています。
- Claudeのページ構造が変更された場合、スクリプトが正常に動作しなくなる可能性があります。
